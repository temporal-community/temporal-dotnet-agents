# Configurable Agent: Activity-Based Handoff

This sample registers Triage and Escalation agents with different instructions and application
tools. `SupportWorkflow` invokes each registered agent through a scoped activity, detects whether
triage requested escalation, and passes a concise handoff prompt to the specialist. Every call uses
a deterministic session ID and request ID generated by the workflow.

## Run

Start Temporal with the required search attributes and configure `OPENAI_API_KEY` and
`OPENAI_API_BASE_URL`:

```bash
DOTNET_ENVIRONMENT=Development dotnet run --project samples/MAF/ConfigurableAgent/ConfigurableAgent.csproj
```
